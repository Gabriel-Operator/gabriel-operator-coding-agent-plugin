# Persona ROI

Work in the user-selected local model repository. Author definitions and synthetic
examples for review; preserve existing IDs and unknown fields. Do not request or
store credentials, import participant rows, call remote APIs, enable runtime
monitoring, execute playbooks, publish or deploy. Runtime activation belongs to
Gabriel Operator or separately authorized live tooling after review.

Read [the valuation contract](references/roi-evidence.md) and
[the operating framework](references/persona-framework.md). Inspect the actual
landing calculator, ontology and workflow/List output fields. Draft
`publishedConfig.roiMonitoring` with its real calculatorPath, stable identities,
evidence requirements, accepted boundary and supported ontology projections.
The public calculator remains disclosed planning assumptions; it is not observed
performance. Do not write real financial records into these drafts.

Time value needs an explicitly saved runner baseline, preparation/review effort,
hourly value and matching currency. Monetary savings need comparable committed
baseline/actual amounts. Preserve withdrawals, negative values and unknown cost.
Known comparable positive cost permits (value-cost)/cost; top-up funding, credit
consumption and provider expense are distinct. Generated rows, budgets and
sandbox actions are not realized returns. Outcome feedback is a reviewable
proposal. Use the existing ROI/Impact sidebar, not a duplicate Home/Coach tab.
